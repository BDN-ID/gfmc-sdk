GFMC SDK — Maven repository

This branch is a static Maven repository for the GFMC SDK. No account and no token are required. Artifacts only — the SDK source is not published here.

The repository URL below points at raw.githubusercontent.com, which serves this branch today. If GitHub Pages is enabled for the repo later, https://bdn-id.github.io/gfmc-sdk/ will serve the identical tree and this page will be its index.

Use it

// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://raw.githubusercontent.com/BDN-ID/gfmc-sdk/gh-pages/") }
    }
}

// app/build.gradle.kts
dependencies {
    implementation("com.sltr.gfmc:gfmc-sdk:1.2.7")
}

On 1.2.7, initialise with GfmcSDKEnv.SANDBOX.

This release moves GfmcSDKEnv.PRODUCTION to stream.minicinema.id, which has no DNS record yet — opening the hub on it fails with NETWORK_ERROR. GfmcSDK.init(context) defaults to PRODUCTION, so pass the environment explicitly:

GfmcSDK.init(context, GfmcSDKEnv.SANDBOX)

SANDBOX and DEV both resolve to stream-dev.minicinema.id, which serves the same hub. Switch to PRODUCTION once BDN confirms the domain is live — nothing else changes.

Google Play Billing resolves automatically from google() — it is declared in this artifact's Gradle module metadata, so do not add it yourself. Keep google() and mavenCentral() in the list; only the SDK itself comes from here.
